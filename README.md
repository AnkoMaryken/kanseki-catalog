# 古代史及汉籍研究工具（中日历史纪年对照查询）

面向汉籍整理工作的研究工具：以公历年份为基准轴，同步查询中国与周边政权（日本、朝鲜半岛、渤海、南诏、大理、越南等）的历史纪年（朝代、年号、君主、干支、生肖），并提供《全球汉籍合璧工程》编目细则查阅、四部分类表查询与《整理工作手册》PDF 在线浏览。

提供两种使用形态：

- **网页版**：静态站点，零依赖，浏览器直接打开
- **桌面版**：Windows 程序（`kanseki-app.exe`），界面资源已内置，双击即用，无需浏览器或网络

## 功能

- **纪年查询**：公历年份 ↔ 中国朝代/年号 ↔ 其他朝代（日本及周边政权）年号，支持干支（如「癸未」）、「年号+干支」（如「万历癸未」）、「年号+片段」模糊补全（如「同治一」→「同治十一年」）、拼音（全拼/首字母缩写）等多种检索方式
- **简繁切换**：右上角「简/繁」一键切换全文显示字形，查询不受字形影响
- **快捷筛选**：按「中国朝代 / 日本 / 朝鲜半岛 / 东北 / 云南 / 越南」分区，可单独筛选某政权全部年号，亦可按君主分组组合筛选
- **CSV 导出**：自定义列与范围导出筛选结果
- **岁时落款常识**：干支、月份、节令、落款、年龄等纪时知识悬浮面板
- **卷数计算器**：页面右下角悬停展开，便于合计丛书卷数
- **编目规范**：2023 / 2025 两版编目细则全文查阅（全文检索、引用示例、著录格式代码块）、四部分类表三级查询
- **工作手册**：内嵌浏览《（修订）全球汉籍合璧工程精华编整理工作手册》PDF 原版
- **账号体系**：注册 / 登录 / 个人中心（头像裁剪、颜色文字）；未配置后端凭据时自动进入演示模式

## 使用

### 网页版

无需构建，直接以静态服务器打开即可（本地开发建议用任意静态服务器，如 `python -m http.server` 或 `npx serve`）：

- `index.html` — 纪年查询主页面
- `guide.html` — 使用介绍
- `catalog.html` — 编目规范（细则 + 分类表 + 工作手册 PDF）
- `embed.html` — 快速跳转
- `changelog.html` — 更新日志
- `login.html` / `signup.html` / `profile.html` / `terms.html` / `privacy.html` — 账号相关页面
- `admin.html` — 管理员工作台（登录门禁，默认账号见 `admin-config.example.js`）

在线访问：https://ankomaryken.github.io/kanseki-catalog/index.html

### 桌面版（Windows）

双击 `app/launch-app.bat`，或直接运行 `app/tauri/target/release/kanseki-app.exe`。

桌面版把网页版各页面整合为单窗口应用，左侧栏统一导航，分四组共 11 项：

- **纪年查询**：纪年查询
- **编目规范**：细则查阅 / 分类表查询 / 工作手册
- **说明文档**：使用介绍 / 更新日志
- **应用**：快速跳转 / 编目记录 / 同步设置 / 账号 / 关于

左上角为「收起侧栏」与「窗口」按钮（最小化 / 最大化 / 关闭 / 置顶 / 全屏 / 居中 / 三档尺寸预设），侧栏底部为用户登录区（登录后显示头像昵称，可进个人中心或退出）与「切换主题 / 打开网页版」。账号数据与网页版共用。

重新构建桌面版（需 Rust MSVC 工具链与 Tauri CLI）：

```bash
cd app/tauri
export PATH="$HOME/.rustup/toolchains/stable-x86_64-pc-windows-msvc/bin:$PATH"
../node_modules/.bin/tauri build --no-bundle    # 仅出 exe；去掉 --no-bundle 出安装包
```

> **注意**：重编译前须先退出正在运行的程序（`taskkill //F //IM kanseki-app.exe`），否则链接阶段会因文件被占用而报 LNK1104。

## 技术要点

- 网页版单文件零依赖：CSS/JS 内嵌于各 HTML，数据内嵌简体存储，运行时经内置简繁映射转换
- 外部仅引用 `conv_tables.js`（简繁映射）、`pinyin_data.js`（拼音检索）、`knowledge.js`（岁时常识）、`catalog_data.js`（编目细则数据）
- 桌面版：Tauri v2 + Rust，前端为 `app/src/`，构建时从仓库根同步网页版各页面至 `app/dist/`
- 数据构建脚本：`build_data.py`（纪年数据）、`build_conv_tables.py`（简繁表）、`build_v14.py`（编目细则 Markdown → JS）、`build_pinyin.py`（拼音表）、`build_neighbor_data.py`（周边政权年号）、`build_admin_data.py`（工作台数据）

## 测试

`tests/` 目录含网页版数据单测与真实浏览器端到端测试（playwright-core + 本机 Chrome），`app/tests/` 含桌面版单元与界面测试。

运行测试需先启动本地静态服务（网页版 8765、桌面版 8766），并设置 `NODE_PATH` 指向 playwright-core 所在目录，详见各测试文件头部注释。

## 说明

本项目为学术参考工具，数据覆盖中国（前 841 年 — 1912 年）及周边政权（日本 645 年 — 2026 年）的朝代、年号、君主、干支、生肖等纪年信息。使用时请以原始文献为准。
