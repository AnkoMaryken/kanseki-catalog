# 日本汉籍编目工具（中日历史纪年对照查询）

面向汉籍整理工作的单文件零依赖网页工具：以公历年份为基准轴，同步查询中国与日本的历史纪年（朝代、年号、君主、干支、生肖），并提供《全球汉籍合璧工程》编目细则查阅、四部分类表查询与《整理工作手册》PDF 在线浏览。

## 功能

- **纪年查询**：公历年份 ↔ 中国朝代/年号 ↔ 日本时代/年号，支持干支（如「癸未」）、「年号+干支」（如「万历癸未」）、「年号+片段」模糊补全（如「同治一」→「同治十一年」）等多种检索方式
- **简繁切换**：右上角「简/繁」一键切换全文显示字形，查询不受字形影响
- **CSV 导出**：自定义列与范围导出筛选结果
- **岁时落款常识**：干支、月份、节令、落款、年龄等五大类纪时知识悬浮面板
- **编目规范**：2023 / 2025 两版编目细则全文查阅（全文检索、引用示例、著录格式代码块）、四部分类表三级查询
- **工作手册**：内嵌浏览《（修订）全球汉籍合璧工程精华编整理工作手册》PDF 原版

## 使用

无需构建，直接以静态服务器打开即可（本地开发建议用任意静态服务器，如 `python -m http.server` 或 `npx serve`）：

- `index.html` — 纪年查询主页面
- `guide.html` — 使用介绍
- `catalog.html` — 编目规范（细则 + 分类表 + 工作手册 PDF）
- `changelog.html` — 更新日志

## 技术要点

- 单文件零依赖：CSS/JS 内嵌于各 HTML，数据内嵌简体存储，运行时经内置简繁映射转换
- 外部仅引用 `conv_tables.js`（简繁映射表）与 `catalog_data.js`（编目细则数据）
- 数据构建脚本：`build_data.py`（纪年数据）、`build_conv_tables.py`（简繁表）、`build_v14.py`（编目细则 Markdown → JS）
