使用介绍

本工具面向古代史与汉籍研究，围绕「查得快、录得准」两件事设计：既能查公历年份对应的中国与东亚周边政权纪年，也能检索古籍类目、日本所藏汉籍与日本国立公文书馆馆藏，并按「全球汉籍合璧工程」的规范查阅细则、著录书目。网页版打开即用；桌面版（Windows）另有原站直连检索与整册下载等能力。下文按功能分区逐项说明，右上角「章节树」可随时跳转。

一、快速上手

网页版与桌面版

  • 网页版：浏览器直接打开站点页面即可，无需安装；纪年、类目、细则、工作手册等都能用。
  • 桌面版：Windows 单文件程序，双击运行；分「安装版」与「免安装版」，功能完全相同——免安装版可放 U 盘，删掉文件即等同卸载。
  • 纪年、类目、细则、工作手册、编目记录等离线可用；「汉籍检索（日本）」「日本国立公文书馆」及其下载功能需要联网，由桌面版经本机网络栈直连原站。

界面总览（桌面版）

  • 标题栏：左侧是「收起侧栏」与「窗口」菜单；右侧依次为简/繁切换、GitHub 项目页、明暗主题、下载情况，最右是最小化 / 最大化 / 关闭三键。
  • 左侧栏分五组：查询（工作台、纪年查询、古籍类目）、检索（汉籍检索（日本）、日本国立公文书馆）、编目（编目记录）、资料（细则查阅、分类表、工作手册）、系统（快速跳转、使用介绍、更新日志）。
  • 收起侧栏：点标题栏最左侧按钮，内容区自动铺满；收起后左下角出现浮出导航按钮，点开即可切换功能。
  • 窗口菜单：最小化 / 最大化 / 关闭 / 窗口置顶 / 全屏（F11）/ 窗口居中，以及标准（1280×800）、宽广（1600×1000）、紧凑（1100×720）三档尺寸。
  • 拖拽窗口四边或四角可缩放；双击标题栏可在最大化与还原之间切换。

关闭窗口不会退出程序（桌面版）

点右上角「关闭」只是把窗口收进右下角托盘，程序仍在后台运行，正在进行的下载会继续跑完。点托盘图标（或右键菜单「显示主窗口」）即可回到界面；托盘菜单里还有「下载中心」；只有菜单里的「退出」才真正结束程序。

第一次使用建议：先在工作台看一眼常用入口，再到「纪年查询」随手输一个年份试试检索；需要编目时，从「资料」组进入细则查阅与工作手册对照著录。

二、纪年查询

以公历年份为基准轴，同时给出中国朝代、年号、君主、干支、生肖，以及日本、朝鲜半岛、渤海、南诏、大理、越南等周边政权的年号与君主。打开即显示全部年份表，不必先输入年份。

能查什么

  • 公历年份：如 1583、前841（公元前）。
  • 干支：如 癸未，列出所有癸未年。
  • 中国年号：如 万历、贞观，或完整写法 万历十一年。
  • 其他政权年号：如 明治（日本）、天授（高丽）、嘉隆（阮朝）。
  • 君主 / 天皇名：如 康熙、后醍醐。
  • 年号 + 干支：如 万历癸未，直接定位到 1583 年。
  • 拼音：全拼或首字母，如 jingtai／jt → 景泰，wuchen／jz → 戊辰 / 甲子。

简体、繁体输入等价（万历 与 萬曆 皆可）；按住输入会实时弹出搜索建议，点建议或按回车即可跳转。点搜索框右侧的「清除」可清空关键词并回到全量列表。

表格、筛选与小工具

  • 表格按年份分页（每页 50 年），列出区域、朝代·幕府、年号、君主、干支与公元起止；点年号即可复制。
  • 快捷筛选：按中国朝代与周边政区分区，点政权名即筛出该政权全部年号；右侧可按君主分组点选，可组合使用。
  • 搜索历史：点空搜索框可看最近 10 条记录，点击回填，可一键清空。
  • 纪年小窗（桌面版）：侧栏「纪年查询」行尾的小图标，打开一个可缩放、默认置顶的小窗，输年份 / 年号 / 干支即查，点结果即复制「万历十五年（1587）」这样的写法，适合边编目边查。
  • 岁时落款常识（右下角「歲」按钮）：干支别称、农历月份雅称、季令节令、书画落款规范、古代年龄称谓五节。
  • 卷数计算器（右下角「卷」按钮）：做丛书卷数的加减合计。

三、古籍类目查询

以《中国古籍总目》全量著录（177,107 条）与「全球汉籍合璧工程」类目对照为基础：输入书名、著者、分类或合璧类目，即可看到某书在两套分类体系中的位置与对应关系。

  • 检索：支持空格分词（多词按「且」匹配）、字段限定（书: 著: 类: 合: 判:）与错字容错（打错一两个字也能命中）。
  • 结果：每条给出部 / 类 / 属与合璧对应类目，并用三态色标提示判定：完全相同、可对应、无对应。
  • 检索历史：点检索框即显示最近检索词，可单条删除或清空；与纪年查询的历史分开保存。
  • 批量查询（桌面版）：每行一条（书名 / 著者 / 类目，# 开头为注释），逐条给出命中数、判定分布与前三条示例，结果可导出 CSV。
  • AI 复检（桌面版）：选中某条或直接复检搜索框内容，把当前分类与网络查证资料交给 DeepSeek 复核，回答首行给出「一致 / 可能不一致 / 不一致」结论与修改建议。AI 结果仅供核对参考，最终以原目录与馆方著录为准。

AI 复检需要在设置窗口中配置 DeepSeek API Key，Key 只保存在本机；网页版受浏览器跨域限制，不提供该功能。

四、汉籍检索（日本）

仅桌面版可用。数据源为京都大学人文科学研究所运营的《全國漢籍データベース》，收录日本 76 家机构约 92.5 万条中文古籍记录。

  • 检索：按書名 / 著者名 / 刊年 / 出版者 / 子目 / keyword 检索，并可多选所藏机构；主检索条常驻，其余条件收在可折叠的高级筛选里，检索后自动收起。
  • 结果与详情同屏、可全宽切换：点条目看详情，返回后原选中行保持高亮；详情含四部分类、索书号、册数、子目清单与卷头书影链接，书影可点开原站查看。
  • 筛选开关带条件计数徽标，收起时显示一行条件摘要；摘要按提交瞬间的条件回显，避免与当前结果对不上。

注意：原站只提供 http 且不返回 CORS 响应头，网页版无法直连，因此本功能只在桌面版提供，界面会明确说明而不是静默失败。原站按日文 / 繁体字形著录，检索时请用原字形（如 論語 而非 论语）；人名异称不归一（陶潛 与 陶淵明 需分别查）。原站偶发限流，中断时程序会自动重试，并保留已取到的部分结果、标注「不完整」。

五、日本国立公文书馆检索

仅桌面版可用。直连国立公文書館デジタルアーカイブ，检索其内閣文庫旧藏汉籍等数字档案。该馆目録元数据以 CC0 开放，数字内容可依馆方条款自由利用（建议注明出典）。

检索条

从左到右：检索范围（全部 / 题名 / 作成者 / 件名·细目 / 参照代码）→ 关键词 → 「检索」→「详细检索」（带已选条件数角标）→「清空」。结果区上方的状态行可切换每页显示件数（20 / 50 / 100 / 200）并翻页。

详细检索

展开后可组合使用：资料种别（簿册 / 件名·细目 / 资料群，可多选）、图像等种类、利用限制、保存场所、作成年起止、移交元机关等、旧藏（文库）、参照代码起止。面板底部是「内閣文庫 汉籍分类」：内閣文庫 / 漢籍 / 經 / 史 / 子 / 集 / 叢書 / 新書 / 和書，可一键限定，也可点旁边的 ↗ 到原站分类页逐层浏览。

结果与详情

  • 每条结果给出资料种别、标题、階層链与著录字段，并附可点击的原站链接。
  • 详情含 レファレンスコード、階層、保存場所、利用制限、IIIF マニフェスト等信息与缩略图。
  • 可「复制引用例」（按馆方建议注明出典），也可「参考此记录新建编目记录」——只带入有把握的字段，卷数 / 版式 / 函册等留空由编目者按实物著录。
  • 结果条目右侧有「下载」按钮，用法见下一节。

六、下载与下载中心

仅桌面版可用。覆盖「日本国立公文书馆」的整册下载：单本、批量与下载中心。

单本下载：三步

  1. 在检索结果里点某条目右侧的「下载」；
  2. 面板先解析「这本书一共有多少册」并给出粗略预估（册数、约多少页 / 多少 MB / 多久）；
  3. 确认下载位置（可「浏览…」自选文件夹，会记住上次选择）与命名方式，点「开始下载」。

命名方式：三套模板各自独立

  • 目录名 / 每册文件名 / 压缩包名三套模板互不影响，改完会被记住，下次自动带出；
  • 可用字段：{书名} {分类} {册次} {册名} {册ID} {主册ID} {总册数} {日期}，点面板上的字段按钮即可插入；
  • 支持补零：{册次:03} → 001；例：{册次:03}_{册名} → 001_古逸叢書叙目.pdf；
  • 内置三套预设，也有实时目录树预览；同名文件自动加序号，不会互相覆盖。

超过 50 页的册自动合并

站方一次最多提供 50 页，超过的册会先落成若干分卷；下载完自动合并成一个完整 PDF（不重新压缩，画质与原分卷一致），并核对页数无误后才删除分卷。万一合并失败会保留分卷并写明原因。

下载中心

点标题栏右侧的「下载情况」进入下载中心视图：可看当前书名、第几册 / 共几册、实时速度、已下载大小、本册页数与整体进度，并可暂停 / 继续 / 取消 / 打开文件夹。下载在后台进行，切到其他功能查看不影响任务；右上角按钮带进度角标，完成或失败会弹通知与提示音。

批量下载

  1. 点检索条右侧的「批量下载」；
  2. 粘贴一批条目，每行一条，三种写法都支持：纯数字 ID（591091）、原站链接、索书号（子046-0012，全角也认）；# 开头是注释行，重复条目自动去重；
  3. 点「读取书目信息」，逐条读出书名与册数供核对；一个索书号命中多条时会出现下拉框供选择；
  4. 勾选要下的条目 →「加入队列并开始」：下完一本自动开始下一本；队列进度会写入输出目录，中断后可「恢复上次队列」续跑。

失败处理与「零缺册」

某一本或某一册失败时，右下角弹通知并响提示音，下载中心给出四个选择：重试这一本 / 略过继续下一本 / 暂停整批（保留进度）/ 取消整批。整个流程按「先定清单、再下数据」执行：册清单先写盘冻结，逐册下载并核对页数，打包前还要过完整性门禁（册数、序号连续、页数、文件名唯一）。任何一册没下完或页数不符，就不会生成压缩包，而是列出缺哪几册，可「只重试未完成册」补齐。

产物与合规

最终每个书目目录里只保留 PDF 与压缩包；下载过程中会留有任务文件供断点续传，完成后自动清理。完成横幅上有「打开所在文件夹」。该馆 robots.txt 对 /contentDownload/* 设为 Disallow，因此本功能只在你逐次点选或逐条提交时发起，默认一次 1 册、册与册之间有间隔；请勿用于无人值守的整库抓取，整库需求请走正式渠道向馆方咨询。

七、编目规范

「资料」组下的三项内容：细则查阅、分类表、工作手册。三者都是内嵌页面，页头右上角的「章节树」可随时跳转。

细则查阅

  • 提供 2025.10 修订与 2023.09 修订两版编目工作细则，页头右上角切换版本；两版采用同一套章节树与正文排版。
  • 正文为一篇连续文档，支持全文检索：输入关键词后命中处高亮，可上下条定位。
  • 章节树浮出按钮固定在页头，滚动阅读时始终可点，选中章节即跳转并自动收起。

分类表

按标准四部分类（经、史、子、集）加类丛部与附新学类组织，共 66 类。每一类给出收录说明与代表古籍举例，可按部筛选，也可直接搜类名、说明或书名；支持繁简通检（输入繁体同样命中）。分类表内容以《编目细则》与工作手册为准。

工作手册

内嵌浏览《（修订）全球汉籍合璧工程精华编整理工作手册》PDF 原版，可直接翻页、缩放与打印。

八、编目记录

按「全球汉籍合璧工程」编目表格模板著录馆藏汉籍，数据保存在本机（IndexedDB）。

当前状态：「编目记录」仍在完善中（侧栏带「未上线」标记），请暂勿用于正式编目；下列能力先作了解，正式启用后以界面实际行为为准。

  • 著录：14 个字段按模板排列；必填项留空也能先保存，边编边补，界面会提示「还有 N 项带 * 的必填未填」。
  • 导入：支持一键导入 .xlsx / .csv / .tsv 编目表，表头按模板自动对应（简繁 label 与常见别名都能认），中文 GBK 编码的 CSV 也能读。
  • 预览与导出：卡片 / 表格（同模板 14 列）/ 文字（按著录格式成文）三种预览随时切换；可导出表格（CSV）或文字（TXT）。
  • 检索面板带入：在国立公文书馆记录详情里点「参考此记录新建编目记录」，只带入有把握的字段。
  • 管理：按書名 / 索書號 / 著者 / 類目搜索，可排序、编辑与删除；可随同步功能备份。

九、快速跳转

把常用站点与检索入口收在一页，以卡片网格排列，点卡片即在新标签页打开目标网站。

  • 内置入口：典津、识典古籍、国学大全、日本所藏中文古籍数据库、日本国立公文书馆、古籍觅宝、读秀学术搜索、PaddleOCR、GitHub、DeepSeek 网页版与桌面版下载页。
  • 读秀需用机构账号登录，可使用 CARSI 烟台大学账号。

  • 顶部筛选框可按名称或网址过滤。自定义链接保存在本机浏览器中，刷新、重开都还在。

十、账号、同步与设置

账号

  • 桌面版侧栏底部是用户区：未登录显示「登录」，可在软件内完成登录与注册；登录后显示头像与昵称，菜单含个人中心、设置与退出登录。
  • 个人中心可更换头像（上传图片并裁剪 / 颜色加文字 / 恢复默认）、修改昵称、查看邮箱。
  • 网页版与桌面版共用同一套账号数据（同一浏览器 / 环境中登录一次即可）；未配置云端凭据时会自动进入本地演示模式，不影响其它功能。

同步

在设置窗口的「同步设置」中配置 WebDAV（如坚果云），即可把编目记录等本机数据备份到自己的网盘；侧栏底部的状态灯显示同步状态。凭据只保存在本机。

设置窗口

点侧栏用户区菜单中的「设置」打开独立设置窗口，分区包括：个人中心、同步设置、API 管理、外观与快捷键、关于。其中：

  • API 管理：配置 DeepSeek 的 API Key、模型与接口地址，供「AI 复检」与「问问 AI」使用；Key 仅存本机，可一键清除。
  • 外观与快捷键：查看 / 调整与主题、快捷键相关的偏好。
  • 关于：查看程序版本、运行环境与窗口尺寸。

十一、界面、主题与快捷键

  • 简 / 繁切换：标题栏右侧的分段按钮，切换后作用于整个界面（外壳与所有内嵌页面）；查询结果不受字形影响，简繁输入都能命中。
  • 明暗主题：标题栏右侧的主题按钮，一键在浅色 / 深色间切换，偏好会保存。
  • GitHub：标题栏右侧的 GitHub 按钮，可打开项目主页查看源码、更新与问题反馈。
  • 收起侧栏：标题栏最左侧按钮；收起后左下角出现浮出导航按钮。
  • 快捷键：F11 全屏；Esc 关闭浮层（详细检索、章节树、显示件数下拉、弹窗等）；纪年表格中点击年号即复制。
  • 托盘（桌面版）：关闭窗口即缩到托盘，下载继续；托盘菜单可显示主窗口、打开下载中心或退出。

十二、常见问题与反馈

为什么「汉籍检索（日本）」「日本国立公文书馆」在网页版用不了？

这两个站点不返回 CORS 响应头（后者部分端点如此），浏览器受同源策略限制无法直接取数。桌面版内置网络桥直连原站，因此这两项检索与下载仅桌面版可用；界面会明确说明限制，不会静默失败。

检索不到结果怎么办？

原站按日文 / 繁体字形著录，请按原字形输入（如 論語 而非 论语）；也可放宽条件：检索范围改为「全部」，取消资料种别、利用限制、作成年与分类限定。

下载卡住、或某一册失败怎么办？

原站偶发限流与连接重置，程序会自动重试；仍失败时在下载中心选「重试 / 略过 / 暂停 / 取消」。下载进度写在输出目录的任务文件里，重开后可继续，已完成的册不会重下。

下载的文件在哪里？为什么没有生成压缩包？

文件默认放在系统「下载」目录下、按你设定的目录名模板建文件夹；下载中心与完成横幅里都有「打开所在文件夹」。只要有任何一册没下完或页数对不上，完整性门禁就会拒绝打包并列出缺册——这是为了避免「缺册却看似完整」，补齐后即可打包。

关闭窗口后程序去哪了？

去右下角托盘了，下载继续跑。点托盘图标即可回来；要真正退出请用托盘菜单的「退出」。

数据存在哪里？换电脑怎么办？

编目记录与偏好存在本机（IndexedDB / 浏览器本地存储）；配置 WebDAV 同步后，编目记录可备份到自己的网盘。清理浏览器数据或更换设备前，请先确认同步已完成。

更新日志与问题反馈在哪里？

历次版本的功能新增、调整与修复记录在「系统」组的「更新日志」中；如需反馈问题或建议，可通过标题栏的 GitHub 按钮进入项目主页提交。本工具为学术参考用途，纪年与馆藏数据来自各公开数据源，使用时请以原始文献与馆方著录为准；AI 生成内容仅供核对参考。
