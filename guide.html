一快速上手

两种使用形态

  • 网页版：静态站点，用浏览器直接打开网页版首页即可，无需安装。
  • 桌面版：Windows 单文件程序，双击即运行；界面资源已内置，查询类功能断网也能用。 分「安装版」与「免安装版」两种，功能完全相同——免安装版可放 U 盘随身带，删文件即卸载。

界面总览（桌面版）

  • 顶部标题栏：左侧为「收起侧边栏」「窗口」菜单与「简/繁」切换； 右侧依次是「下载中心」按钮（图标为下载箭头，见第六节）、最小化、最大化、关闭。
  • 窗口菜单：最小化／最大化／关闭／窗口置顶／全屏（F11）／窗口居中，以及标准(1280×800)、宽广(1600×1000)、紧凑(1100×720) 三档尺寸。
  • 左侧栏：分六组——纪年查询、古籍类目查询、日本藏本检索、编目规范、说明文档、应用； 底部是登录区与「切换主题」「打开网页版」。
  • 右侧主区：显示当前功能页面；拖拽窗口四边或四角可缩放，双击标题栏可最大化／还原。

关闭窗口不会退出程序（桌面版）

点右上角「关闭」只是把窗口收进右下角托盘，程序仍在后台运行——正在进行的下载任务会继续跑完。

  • 点托盘图标（或右键菜单「显示主窗口」）即可回到界面；
  • 托盘右键菜单还有「下载中心」，可直接打开下载面板；
  • 只有托盘菜单里的「退出」才真正结束程序。

哪些功能需要联网

纪年查询、古籍类目查询、编目规范、工作手册、编目记录均离线可用； 「汉籍检索（日本）」「国立公文书馆检索」及其下载功能需要联网（由桌面版经本机网络栈直连原站，不经浏览器）。

二纪年查询

如何查询

在顶部搜索框输入关键词后，下方会实时弹出搜索建议，点击建议或按回车即可跳转到对应年份；也可输入后点「查找」。

支持模糊补全：输入「年号 + 片段」会自动联想完整写法。例如 同治一 → 「同治十一年」； 明治三 → 「明治三十一年」「明治三十二年」等全部候选；永乐一 → 「永乐十一年」「永乐二十一年」。

可以查什么

  • 公历年份：如 1583、前841（公元前）。
  • 干支：如 癸未，会列出所有癸未年。
  • 中国年号：如 万历、贞观，以及完整写法 万历十一年。
  • 其他政权年号：日本、朝鲜半岛、渤海、南诏、大理、越南等，如 明治、天授（高丽）、嘉隆（阮朝）。
  • 君主／天皇名：如 康熙、后醍醐。
  • 年号 + 干支：如 万历癸未，精确定位到 1583 年。
  • 拼音：全拼或首字母均可，如 jingtai／jt → 景泰，wuchen／jz → 戊辰／甲子。

简体、繁体输入等价（万历 与 萬曆 皆可）；界面显示字形由「简/繁」按钮控制。

快捷筛选、导出与两个小工具

  • 快捷筛选：按「中国朝代 / 日本 / 朝鲜半岛 / 东北 / 云南 / 越南」分区，点政权名即筛选该政权全部年号，右侧可按君主分组点选，可组合使用。
  • 导出 CSV：点表格上方「导出 CSV」，自选导出列与范围（全部筛选结果 / 仅当前页）。
  • 搜索历史：点空搜索框可看最近 10 条记录，点击回填，右上角「清空」清除。
  • 岁时落款常识：右下角「歲」按钮 → 月份雅称、季令、干支生肖、书画落款规范等。
  • 卷数计算器：右下角「卷」按钮，悬停展开迷你计算器，便于合计丛书卷数。
  • 纪年小窗（桌面版）：在侧栏「纪年查询」行尾的小图标，可另开一个 460×620 的小窗， 默认置顶、可缩放，输年份／年号／干支即查，点行或复制键即复制「万历十五年（1587）」这样的结果，适合边编目边查。
三古籍类目查询

以《中国古籍总目》与「全球汉籍合璧工程」类目对照为基础，检索框可输入 书名 / 著者 / 分类 / 合璧类目， 支持空格分词与错字容错（打错一两个字也能命中）。

  • 结果可按「有对应 / 无对应」等情况筛选，用于判断某书在合璧工程里应归入哪个类目；
  • 可对当前筛选结果提问（例如「这些『无对应』的条目按内容应归入哪个合璧类目？」），由 AI 辅助判断；
  • 检索结果可直接参考，或复制到编目记录中使用。
四汉籍检索（日本・全國漢籍データベース）

仅桌面版可用。数据源为京都大学人文科学研究所运营的《全國漢籍データベース》，收录日本 76 家机构约 92.5 万条中文古籍记录。

  • 检索方式：按書名／著者名／刊年／出版者／子目／keyword 检索，并可限定所藏机构。
  • 记录详情：四部分类、索书号、册数、子目清单、卷头书影链接等。
  • 书影：详情中的链接可点开原站查看卷头图像。
  • 该站只提供 http 且不返回 CORS 头，因此网页版无法直连；桌面版面板内会明确提示，不做静默失败。
五国立公文书馆检索（国立公文書館デジタルアーカイブ）

仅桌面版可用。日本国立公文书馆数字档案，内含内閣文庫旧藏汉籍（如「重要文化財（漢書）」）。目録元数据以 CC0 开放。

检索条（一整行）

从左到右：检索范围（全部／题名／作成者／件名·细目／参照代码）→ 关键词 → 「检索」→「详细检索 ↓」（带已选条件数角标）→「清空」。

检索条下方、结果区上方的那一行是状态与分页行，其中「显示件数：N 件」按钮可点开浮动下拉， 选择每页显示 20／50／100／200 条；它的右边就是「← 上一页／下一页 →」。

详细检索（浮动面板）

点「详细检索 ↓」展开，可组合使用：资料种别（簿册／件名·细目／资料群，可多选）、图像等种类、 利用限制、保存场所、作成年（起止，公历年）、移交元机关等、旧藏（文库）、参照代码（起止）。 面板底部是「内閣文庫 汉籍分类」区：一键把检索限定在 内閣文庫／漢書（中文典籍）／經／史／子／集／叢書／新書／和書， 每项旁的 ↗ 可直接到原站分类页浏览（不需要关键词）。

结果与详情

  • 每条结果给出 No.、资料种别、标题、階層链与著录字段，信息末尾一律附可点击的原链接；
  • 点条目可看 JSON-LD 详情（レファレンスコード、階層、保存場所、利用制限、IIIF マニフェスト等）与缩略图；
  • 详情页可「复制引用例」（按馆方建议注明出典），或「参考此记录新建编目记录」——只带入有把握的字段， 卷数／版式／函册等留空由编目者按实物著录，绝不臆造；
  • 结果条目右侧有「下载」按钮，用法见下一节。
六国立公文书馆下载（单本 / 批量 / 下载中心）

单本下载：三步

  1. 在检索结果里，点某条目右侧的「下载」；
  2. 弹出面板先解析「这本书一共有多少册」并给出粗略预估（册数、约多少页／多少 MB／多久）；
  3. 确认下载位置（可点「浏览…」自选文件夹，会记住上次选择）与命名方式，点「开始下载」。

命名方式：三套模板各自独立

  • 目录名 / 每册文件名 / 压缩包名三套模板互不影响，改完会被记住，下次自动带出；
  • 可用字段：{书名} {分类} {册次} {册名} {册ID} {主册ID} {总册数} {日期}，点面板上的字段按钮即可插入；
  • 支持补零：{册次:03} → 001；例：每册文件名填 {册次:03}_{册名} → 001_古逸叢書叙目.pdf；
  • 内置三套预设（编目习惯／极简／原站式），也有实时目录树预览；同名会自动加 _2、_3，不会互相覆盖。

超过 50 页的册会自动合并

站方规定一次最多下载 50 页，所以 86 页的书原本会得到两个分卷（书名_1-50.pdf、书名_51-86.pdf）。 现在下载完会自动合并成一个完整 PDF，合并过程不重新压缩（画质与原分卷一致），并核对页数无误后才删除分卷； 万一合并失败会保留分卷并在报告里写明原因。

下载中心：一边下载一边干别的

点标题栏右上角、最小化旁边的「下载」按钮（带进度角标）打开右侧抽屉：

  • 可看当前书名、第几册/共几册、实时下载速度、已下载大小、本册页数与整体进度；
  • 底部可暂停 / 继续 / 取消 / 打开文件夹；
  • 抽屉是浮层，不挡住其它功能——下载时照常检索、查纪年、编目；切到别的页面它也不会消失。

批量下载：一次提交多本，排队逐本下

  1. 点检索条右侧的「批量下载」；
  2. 粘贴一批条目，每行一条，三种写法都支持：纯数字 ID（591091）、原站链接 （https://www.digital.archives.go.jp/file/1081945）、索书号（子046-0012，全角 子０４６－００１２ 也认）； # 开头是注释行，重复条目会自动去重；
  3. 点「读取书目信息」——逐条读出书名与册数供核对；若一个索书号命中多条 （例如同时有簿冊与各子册），该行会出现下拉框让你挑正确的一条；
  4. 勾选要下的条目 → 「加入队列并开始」：下完一本自动开始下一本；
  5. 队列进度写在输出目录的 _批量队列.json，中断后重开面板可「恢复上次队列」续跑。

失败怎么办

某一本/某一册失败时，右下角会弹通知并响提示音，下载中心里给出四个选择： 重试这一本 / 略过继续下一本 / 暂停整批（保留进度）/ 取消整批。已完成的册不会重下。

不会漏册（重要）

本功能按「先定清单、再下数据」执行：册清单先写盘冻结，逐册下载并逐册核对页数， 打包前还要过一道完整性门禁（册数、序号连续、页数、文件名唯一）。 任何一册没下完或页数不符，就不会生成压缩包，而是在界面上列出「缺哪几册」，可点「只重试未完成册」补齐。

产物与出典

每册一个 PDF，同目录另有 _任务.json（断点）、_报告.csv（每册通道与 SHA-256）、 _manifest.jsonl（溯源清单）；完成横幅上有「打开所在文件夹」。 该馆目録为 CC0、数字内容可自由复制改変再发布，建议注明出典（如「国立公文書館所蔵」），出典会写进 PDF 与清单。

使用提醒：该站 robots.txt 对 /contentDownload/* 设为 Disallow， 因此本功能只在你逐次点选或逐条提交时才发起下载，默认一次 1 册、册与册之间有间隔。 请勿用它做无人值守的整库抓取；整库级需求请走正式渠道（ジャパンサーチ API 或向馆方咨询供数）。

  • 登录／注册：侧栏底部可登录；未配置后端凭据时自动进入演示模式，不影响本地功能。

  • 简 / 繁切换：标题栏左侧「简/繁」按钮，全站显示字形即时切换（查询不受字形影响）。

十一常见问题

为什么「汉籍检索（日本）」「国立公文书馆」在网页版用不了？

这两个站点不返回 CORS 头（后者部分端点如此），浏览器出于同源策略无法直接取数。 桌面版内置网络桥直连原站，因此这两项功能仅桌面版可用，面板内会明确说明而不是静默失败。

检索不到结果怎么办？

原站按日文／繁体字形著录，请按原字形输入（如 論語 而非 论语）； 也可放宽条件：检索范围改「全部」、取消资料种别／利用限制／年代／分类限制。

下载卡住、或某一册失败怎么办？

该站偶发限流与连接重置，软件会自动重试；仍失败时会在下载中心给出「重试／略过／暂停／取消」。 下载进度写在输出目录的 _任务.json 里，重开后可继续，已完成的册不会重下。

下载的文件在哪里？

默认在「下载 / 国立公文书馆下载」下，按你设定的目录名模板建文件夹；完成横幅或下载中心里都有「打开所在文件夹」。

为什么压缩包没生成？

只要有任何一册没下完或页数对不上，完整性门禁就会拒绝打包，并在界面列出缺哪几册—— 这是为了避免出现「缺册却看似完整」的压缩包。补齐后即可打包。

关闭窗口后程序去哪了？

去右下角托盘了（下载继续跑）。点托盘图标即可回来；要真正退出请用托盘菜单的「退出」。
